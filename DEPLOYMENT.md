# Selective Cinema

This repository contains the source manuscript for *Selective Cinema*.

The manuscript is organized as a multi-file LaTeX project:

- `main.tex` — document entry point;
- `preface.tex` — preface;
- `introduction.tex` — introduction;
- `ch01-*.tex` through `ch26-*.tex` — chapters;
- `conclusion.tex` — conclusion;
- `appendices.tex` — appendices;
- `bibliography.tex` — bibliography;
- `selective-cinema.pdf` — compiled reference copy.

LaTeX intermediate files are intentionally excluded from version control.

The PDF is retained because it is the rendered publication artifact, while
the `.tex` files remain the canonical editable source.
